# AI创作助手用户使用手册

## 🌟 欢迎使用AI创作助手

AI创作助手是汐律应用中的智能对话工具，专门帮助创作者和学习者将想法转化为具体的作品计划。通过与AI的自然对话，你可以快速构建完整的项目规划，包括目标设定、动机策略和时间安排。

## 🎯 核心功能

### 1. 智能对话引导
- **自然语言交互**：用日常语言与AI交流，无需专业术语
- **流式响应**：实时查看AI回复，提升对话体验
- **阶段式引导**：AI会根据对话内容智能推进创作阶段

### 2. 六大创作阶段
1. **👋 欢迎阶段**：自我介绍，了解你的创作想法
2. **🔍 创意探索**：深入挖掘想法，明确创作方向
3. **📝 信息整理**：整理作品基本信息，设定具体目标
4. **💪 动机增强**：制定动机策略，建立执行计划
5. **✅ 信息确认**：核对所有信息，准备创建作品
6. **🎉 准备创建**：完成规划，可以正式创建作品

### 3. 实时功能
- **新对话**：随时重置对话，重新开始创作
- **快捷回复**：AI提供智能回复建议，加速对话进程
- **信息预览**：实时查看提取的作品信息和动机策略

## 🚀 使用指南

### 开始对话

1. **打开AI创作助手**
   - 在主界面找到AI创作助手入口
   - 点击打开对话界面

2. **首次对话**
   - AI会热情欢迎并询问你的创作想法
   - 可以使用快捷回复快速开始，或直接输入自己的想法

3. **表达你的想法**
   ```
   示例：
   "我想写一本关于时间管理的书"
   "我计划开发一个健身追踪应用"
   "我想学习弹钢琴"
   ```

### 对话技巧

#### 🎯 有效的表达方式
- **明确具体**：清晰描述你想要创作的内容
- **包含目标**：说明你希望通过创作达到什么目标
- **提供背景**：分享相关的背景信息或经验

#### 💡 互动建议
- **积极回应**：对AI的问题和建议给予详细反馈
- **提出疑问**：不确定的地方可以随时提问
- **表达偏好**：告诉AI你的偏好和限制条件

### 阶段详解

#### 1. 欢迎阶段 👋
- **目标**：建立初步了解，收集基本信息
- **AI会询问**：你的创作想法、经验背景、期望目标
- **你需要**：清晰表达创作意向

#### 2. 创意探索 🔍
- **目标**：深入挖掘创意，明确创作方向
- **AI会**：提出深入问题，帮助你细化想法
- **你需要**：详细描述创作内容和目标受众

#### 3. 信息整理 📝
- **目标**：整理作品信息，设定具体目标
- **AI会提取**：
  - 作品名称
  - 预计时长
  - 创作类型
  - 目标描述
- **你需要**：确认信息准确性，必要时进行修改

#### 4. 动机增强 💪
- **目标**：制定动机策略，建立执行计划
- **AI会设计**：
  - WOOP策略（愿望-结果-障碍-计划）
  - 执行意图
  - 动机维持方法
- **你需要**：评估策略可行性，调整计划

#### 5. 信息确认 ✅
- **目标**：核对所有信息，准备创建作品
- **AI会**：总结所有收集的信息
- **你需要**：仔细检查，确认无误

#### 6. 准备创建 🎉
- **目标**：完成规划，创建作品
- **你可以**：点击"创建作品"按钮，将规划转化为正式作品

## 🛠️ 核心操作

### 新对话功能
1. **何时使用**
   - 想要重新开始创作
   - 对话内容偏离主题
   - 需要调整创作方向

2. **如何操作**
   - 点击右上角"新对话"按钮
   - 确认重置对话
   - 开始新的创作对话

3. **注意事项**
   - 重置会清除当前所有对话内容
   - 确保重要信息已经记录或确认

### 快捷回复
- **位置**：对话框底部
- **用途**：加速对话进程，提供回复建议
- **使用**：点击建议内容自动发送

### 信息编辑
- **作品信息**：右侧面板可以实时编辑提取的作品信息
- **动机策略**：可以修改AI生成的动机策略
- **实时同步**：编辑结果会实时同步到创作计划

## 💡 最佳实践

### 对话策略
1. **循序渐进**：跟随AI的引导，逐步深入细节
2. **保持开放**：尝试AI的建议，即使一开始不太确定
3. **具体表达**：使用具体的例子和清晰的描述
4. **积极反馈**：告诉AI什么建议有用，什么需要调整

### 时间管理
1. **设定现实目标**：考虑实际可用时间
2. **分解大任务**：将大项目分解为可管理的小任务
3. **建立习惯**：制定可持续的创作习惯
4. **预留缓冲**：为意外情况预留时间缓冲

### 动机维持
1. **明确目的**：记住为什么要创作这个作品
2. **找到乐趣**：在创作过程中寻找乐趣
3. **建立支持**：寻找创作伙伴或支持群体
4. **庆祝进步**：为每个小成就庆祝

## ❓ 常见问题

### Q: AI可以帮我创作哪些类型的内容？
A: AI助手支持各种创作类型，包括但不限于：
- 写作项目（书籍、文章、小说）
- 技术开发（应用、网站、游戏）
- 学习计划（语言、技能、认证）
- 艺术创作（音乐、绘画、设计）
- 商业项目（创业、产品、服务）

### Q: 如果我对AI的建议不满意怎么办？
A: 你可以：
- 直接告诉AI你不满意某个建议
- 提出修改意见或替代方案
- 要求AI提供更多选择
- 使用新对话功能重新开始

### Q: 我的对话内容会被保存吗？
A: 对话内容在当前会话中会保持，但：
- 使用"新对话"会清除历史对话
- 关闭应用后对话不会自动保存
- 建议及时创建作品来保存重要信息

### Q: 如何确保制定的目标切实可行？
A: AI会帮助你：
- 分析可用时间和资源
- 设定合理的阶段性目标
- 制定具体的执行计划
- 考虑可能遇到的障碍

### Q: 如果创作过程中遇到困难怎么办？
A: AI会在动机阶段帮助你：
- 识别潜在障碍
- 制定应对策略
- 建立支持系统
- 维持创作动力
