# 悬浮窗测试指南

## 问题解决

### 问题现象
用户在主页面打开悬浮窗时，悬浮窗内显示的还是主页面内容，而不是专门的悬浮窗界面。

### 问题原因
悬浮窗入口文件 `src/float-window.tsx` 仍然使用旧的 `FloatWindowApp` 组件，而不是新设计的悬浮窗组件。

### 解决方案
已更新悬浮窗入口文件，使用新的 `FloatWindowManager` 组件。

### 6. 常见问题排查

#### 问题1: 悬浮窗仍然显示主页面内容
**原因**: 入口文件配置错误
**解决**: 确保 `src/float-window.tsx` 使用 `FloatWindowManager`

#### 问题2: 没有作品可选择
**原因**: 作品列表为空或API调用失败
**解决**:
- 检查控制台是否有错误信息
- 确保后端服务正常运行
- 验证作品数据是否正确

#### 问题3: 样式显示异常
**原因**: CSS文件加载失败
**解决**:
- 检查 `float.html` 中的CSS引用
- 确认样式文件路径正确

#### 问题4: 按钮点击无响应
**原因**: 回调函数配置错误
**解决**:
- 检查控制台日志
- 验证回调函数正确绑定
